#                                   RTS OF BLUETOOTH
# 1.Introduction

Bluetooth is a short-range wireless communication technology used to connect devices without physical cables.

It enables wireless communication between nearby devices using radio waves.

Bluetooth is widely used in:

Mobile phones
Smart watches
Wireless earphones
Smart home devices
Healthcare devices

This project demonstrates Bluetooth communication using Cisco Packet Tracer.

# 2.Objective

The objective of this simulation is to:

Understand Bluetooth communication
Simulate Bluetooth-enabled devices
Study wireless data transfer
Analyze Bluetooth connectivity

# 3.Concept of Bluetooth Network

A Bluetooth network connects nearby devices wirelessly.
It establishes communication through:

Device Discovery

Searching for nearby Bluetooth-enabled devices.
Pairing

Connecting two devices securely.

Data Transfer

Sending information wirelessly.

In this simulation:

Portable Music Player acts as sender
Bluetooth Speaker acts as receiver
